# Camel Dataset

This directory contains the camel dataset for training and evaluation.

## Directory Structure
```
camel_data/
├── train/          # Training images
├── val/            # Validation images
├── test/           # Test images
├── meta.json       # Dataset metadata
└── camel_dataset.csv  # Generated dataset CSV
```

## Dataset Format
- Images should be in JPG or PNG format
- The `camel_dataset.csv` file will be automatically generated by `prepare_dataset.py`
- The CSV will contain the following columns:
  - filename: Path to the image file
  - rating: Numeric rating (1-10)
  - body_shape: Categorical (poor/average/good/excellent)
  - head_structure: Categorical (poor/average/good/excellent)
  - leg_condition: Categorical (poor/average/good/excellent)
  - coat_condition: Categorical (poor/average/good/excellent)
  - overall_fitness: Categorical (low/medium/high)
